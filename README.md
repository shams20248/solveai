# SolveAI

SolveAI is a professional business services platform designed for consent-based business intake, client proposals, structured request management, and payment verification workflows.

## Included Features
- Professional public landing page
- Admin dashboard for requests and statuses
- User login with JWT authentication
- In-memory request and invoice tracking
- USDT payment instructions on BNB Smart Chain
- Legal pages: Terms, Privacy, Payment Policy
- Docker-ready project structure
